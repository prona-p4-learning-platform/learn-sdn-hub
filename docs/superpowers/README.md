Contains an example for a superpowers session to finish and merge the containerlab branch developed in WiSe 25/26.
This is used as a demo for proper planning and agentic dev skills in our courses.

Using AI for this repo started gradually in WiSe 25/26 and agentic AI is preferred and the use of planning skills
like [superpowers](https://github.com/obra/superpowers) or [spec-kit](https://github.com/github/spec-kit) etc. is
advised for bigger tasks especially for refactoring, implementation of new functions including and increasing at
least a minimalistic set of tests.
