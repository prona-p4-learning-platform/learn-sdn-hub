# System Detective

Your lab instance is a container somewhere on a host. Find out who it is!

Use the terminal to investigate the instance and write your findings to `answers.txt` in the editor — **one answer per line**, nothing else on the line.
Save the file (aka Deploy button above the editor window), then press the check button for each step.
